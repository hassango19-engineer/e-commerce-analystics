# E-commerce Data Analytics

Projet d'analyse de données e-commerce utilisant
Python, PostgreSQL, SQL et Power BI.

## Objectif
Analyser les ventes, les clients, les produits
et les paiements d'une entreprise e-commerce.

## Technologies
- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI
- Git / GitHub

## Pipeline

CSV
 ↓
Python / Pandas
 ↓
Nettoyage
 ↓
PostgreSQL
 ↓
SQL Analytics
 ↓
Power BI

## Analyses réalisées
- Chiffre d'affaires
- Panier moyen
- Top produits
- Top clients
- Analyse par ville
- Analyse par catégorie
- Analyse des paiements
- Évolution mensuelle des ventes
